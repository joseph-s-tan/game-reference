# Game references

Curated static exports for GitHub Pages. The repository root is a small gallery, with each reference under its own directory.

- `pendor/` is generated by `pendor-build-planner/export_pages.py --base-path /game-reference/pendor/`.
- `tennis-elbow/` is generated by `tennis-elbow-planner/export_pages.py --base-path /game-reference/tennis-elbow/` (after `build.py`). It includes the season planner, which keeps plans in the visitor's own browser storage.

Only reviewed public exports belong here. Keep source projects, mod files, local saves, planner storage, and the Obsidian vault outside this repository. GitHub Pages publishes `main` at `/(root)`: <https://joseph-s-tan.github.io/game-reference/>.
