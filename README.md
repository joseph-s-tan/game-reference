# Game references

Curated static exports for GitHub Pages. The repository root is a small gallery, with each reference under its own directory.

- `pendor/` is generated by `pendor-build-planner/export_pages.py --base-path /game-reference/pendor/`.
- `tennis-elbow/` will be added after its public content is reviewed.

Only reviewed public exports belong here. Keep source projects, mod files, local saves, planner storage, and the Obsidian vault outside this repository. GitHub Pages is expected to publish from `main` at `/(root)` after the remote repository exists.
